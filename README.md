# Momentum Projects Website Clone

A high-fidelity, responsive clone of [momentumprojects.in](https://momentumprojects.in/) — modern pre-fab, sustainable architectural construction builders.

## Features
- **Responsive Architecture:** Fully optimized across desktop, tablet, and mobile displays using Bootstrap 5.
- **Dynamic Hero Section:** Pre-fab house assembly animation and HD architectural imagery with preloaded high-priority assets.
- **Interactive Portfolio & Filtering:** Isotope-powered categorization for Building, Construction, Architecture, and Planning projects.
- **Comprehensive Multi-Page Site:**
  - `index.html` / `index.php` (Home)
  - `about-us.html` / `about-us.php` (About Us)
  - `what-we-do.html` / `what-we-do.php` (What We Do / Services)
  - `projects.html` / `projects.php` (Projects Portfolio)
  - `services.html` / `services.php` (Detailed Services)
  - `contact.html` / `contact.php` (Contact Form & Map)
- **Dual Server Compatibility:** Run seamlessly with either a static web server (Node/Python/Nginx) or PHP backend.

## How to Run Locally

### Option 1: Static Web Server (Python)
```bash
python3 -m http.server 8085
```
Then visit: `http://localhost:8085/`

### Option 2: PHP Built-in Server
```bash
php -S localhost:8000
```
Then visit: `http://localhost:8000/`
